# RetinaGuard — Autonomous Diabetic Retinopathy & Ocular Triage Studio

A local, single-page clinical triage workbench. Open it and you land directly in the studio — no landing page, no login.

> Preliminary AI screening decision-support — **not a standalone medical diagnosis**; confirm via dilated slit-lamp/ophthalmic exam.

## Run

**Windows:** double-click `start.bat` (creates `.venv`, installs deps, starts the server, opens the browser).
**Linux/VPS:** `./start.sh`
**Manual:** `pip install -r requirements.txt && python run.py` → http://127.0.0.1:8002

Then click **API Keys** and paste a free key:
- Gemini (`AIza…`) — https://aistudio.google.com/apikey
- Groq (`gsk_…`) — https://console.groq.com/keys

Keys are saved in `retinaguard.db`; `.env` (see `.env.example`) is also read. An in-app key wins over `.env`.

## What it does

5-node pipeline (pure Python, `app/pipeline.py`), streamed live to the tracker:

1. **Ocular Gatekeeper & Modality Classifier** — rejects non-eye images (rejections don't use quota), classifies Fundus vs Anterior, grades gradability
2. **Anatomical Biomarker & Lesion Detector**
3. **ICDR & Ocular Risk Grader** — ICDR 0–4 for fundus; Normal/Mild/Moderate/Urgent for anterior; macular edema risk
4. **Clinical Triage & Referral Timeline** — urgency tier is never lower than a rule-based floor for the grade
5. **Structured Report & Persistence** — saved to SQLite history

Plus: progression compare, referral brief (copy / download `.md`), history drawer, and a grounded Co-Pilot (free — doesn't use quota).

**Rate limit:** 5 full screenings per sliding hour (SQLite); HTTP 429 reports minutes/seconds remaining. Override with `RATE_LIMIT_PER_HOUR`.

## Providers

Gemini REST (`gemini-3.8-flash`, auto-fallback to `gemini-3.6-flash` on 503/504) → Groq REST (`qwen/qwen3.8-27b`). Override via `GEMINI_MODEL`, `GEMINI_FALLBACK_MODEL`, `GROQ_MODEL`. If a model ID is unavailable on your account, set it in `.env`.

Dependencies are limited to `fastapi, uvicorn, httpx, python-dotenv, pillow, python-multipart` — no numpy/opencv/langchain.

## Notes
- Sample images are synthetic illustrations generated by Pillow into `static/samples/` on first start; they are not real patient scans, so model output on them may vary.
- This is a demo, not a certified medical device.

Run this command

Windows (PowerShell):
python -m venv .venv; .\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8002

macOS / Linux (Terminal):
python3 -m venv .venv && ./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8002
